Как это работает

Коротко о криптографии, которая защищает хранилище.

PBKDF2-SHA256

Мастер-пароль превращается в ключ через 310 000 итераций. Это делает перебор медленным.

AES-256-GCM

Все записи шифруются симметричным алгоритмом. Каждое шифрование использует новый случайный IV.

Соль и verifier

Соль случайная и хранится в открытом виде. Verifier позволяет проверить пароль без сохранения ключа.

Ключ в памяти

Ключ живёт в chrome.storage.session и стирается при блокировке или перезапуске браузера.

О проекте

KeyGuard — менеджер паролей в виде расширения для браузера. Учебный проект для 10 класса.

Что умеет KeyGuard

Шифрование

Мастер-пароль, PBKDF2 и AES-256-GCM. В хранилище браузера попадают только зашифрованные данные.

Автозаполнение

Расширение находит форму логина на странице и подставляет сохранённые данные по команде.

Генератор

Криптостойкие пароли нужной длины с настройкой наборов символов и оценкой надёжности.

TOTP и аудит

Коды двухфакторной аутентификации и проверка слабых, повторных и старых паролей.

Проверка утечек

Проверка по базе Have I Been Pwned через k-anonymity: серверу уходит только 5 символов SHA-1.

Резервные копии

Экспорт и импорт зашифрованного файла для переноса хранилища между устройствами.

Какие разрешения используются

storage

Хранение зашифрованного хранилища и настроек. Открытый текст не сохраняется.

activeTab, scripting

Заполнение формы на активной вкладке по явному действию пользователя.

clipboardWrite

Копирование паролей и последующая очистка буфера обмена.

idle, alarms

Автоматическая блокировка при простое и по таймеру.

host_permissions

Доступ к сайтам для автозаполнения и к API Have I Been Pwned для проверки утечек.

contextMenus

Пункт «Заполнить паролем из KeyGuard» в контекстном меню страницы.

Ограничения проекта

KeyGuard — учебный проект, а не сертифицированный менеджер паролей. Нет облачной синхронизации и восстановления мастер-пароля: если его забыть, данные не восстановить. Автозаполнение работает на сайтах с обычной формой логина и может не сработать на нестандартных формах. Проверка утечек требует доступа к интернету. Для реального использования стоит выбрать проверенное решение с открытым кодом.

Технологии

Manifest V3

Актуальная модель расширений Chrome: service worker и минимальные права.

Web Crypto API

Встроенные криптографические функции браузера: PBKDF2, AES-GCM, SHA-1, HMAC.

Chrome Extension API

storage, idle, alarms, contextMenus, scripting и tabs.

Без библиотек

Интерфейс и логика написаны на чистом HTML, CSS и JavaScript.
