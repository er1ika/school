# Демо-сайт «Школьный портал»

Этот сайт нужен только для проверки расширения **KeyGuard**. Он не является настоящим школьным порталом и не отправляет данные на сервер.

## Запуск

Из корня проекта:

```bash
npm run serve:demo
```

Или из этой папки:

```bash
python3 -m http.server 8000
```

Затем откройте <http://localhost:8000>.

> Расширения Chrome не работают на страницах `file://`, поэтому нужен именно HTTP-сервер.

## Что проверить

1. Создайте хранилище в KeyGuard и добавьте запись:
   - тип: «Логин и пароль»;
   - название: «Школьный портал»;
   - сайт: `http://localhost:8000`;
   - логин: `student@school10.ru`;
   - пароль: `SchoolPass!2026`.
2. Откройте демо-сайт и нажмите на иконку KeyGuard.
3. Выберите запись и нажмите «Заполнить» — логин и пароль подставятся в форму.
4. Отправьте форму — появится баннер «Сохранить пароль в KeyGuard?».
5. Во второй форме («Смена пароля») укажите тот же логин и новый пароль, отправьте форму — KeyGuard предложит обновить запись.
6. В настройках KeyGuard откройте «Аудит паролей», чтобы увидеть слабые и повторно используемые пароли.

## Особенности

- Формы не отправляют данные на сервер: используется `preventDefault()`.
- Пароль не сохраняется в localStorage или cookie.
- Сайт специально оформлен как обычный школьный портал, чтобы проверить определение полей логина и пароля.
